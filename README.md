# 🎮 Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using **HTML, CSS, and JavaScript**. Play with two players and find out who wins!

## 🌐 Live Demo

🔗 **Live Link:** [Play Tic Tac Toe](https://tic-tac-toe-code-eight.vercel.app/)

## ✨ Features

- 🎯 Interactive 3×3 game board
- ❌ Two-player mode (X and O)
- 🏆 Automatic winner detection
- 🔄 Reset Game button
- 🆕 New Game functionality
- 🎨 Attractive and simple UI
- 📱 Responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎮 How to Play

1. Player O starts the game.
2. Players take turns clicking an empty box.
3. Get three matching symbols in a row, column, or diagonal to win.
4. Click **Reset Game** or **New Game** to play again.
